# Issue tracker: GitHub

Issues and specifications for this repository live in GitHub Issues at `GeorgesGil/real-madrid-cinematic-experience`. Use the `gh` CLI when repository policy permits GitHub operations.

## Conventions

- Create, read, comment on, label, and close work through GitHub Issues.
- Infer the repository from `git remote -v` when working from a checkout.
- Pull requests are not a request surface for triage.
- A bare issue number may share the GitHub number space with pull requests; resolve its type before acting.

## Publishing from skills

When a skill says to publish to the issue tracker, create or update a GitHub issue. When GitHub writes are unavailable in an isolated agent, write the requested artifact under `docs/` and report the intended issue update in the final handoff.
