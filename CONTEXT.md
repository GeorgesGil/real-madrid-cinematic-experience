# Domain glossary

## Cinematic timeline

The ordered scroll narrative that moves through Crest, Bernabéu, Team, European Royalty, History, Moments, and Future. It is not ordinary page scrolling with unrelated animations.

## Scene

A semantically complete chapter of the cinematic timeline. A scene can contain multiple visual states while preserving one accessible reading order.

## Stable state

The complete, readable presentation that remains when animation is unavailable, JavaScript fails, or reduced motion is enabled.

## Editorial player

The large-format player presentation combining portrait, name, position, number, nationality, appearances, and goals. It is distinct from a generic player card.
